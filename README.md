# The Booth

A Claude Code theme in tribute to Jensen Huang: the boy who washed dishes and bussed tables at Denny's, then sat down in one of its booths in 1993 to start the company whose chips much of modern AI runs on.

- **Light mode is the diner:** cream counter, black coffee, ketchup red.
- **Dark mode is the datacenter at 3 a.m.:** silicon green on near-black.
- **Backdrop (desktop/mobile):** steam from a diner coffee cup turns into circuit traces that run to a grid of glowing cores.
- **Status line (every surface):** each finished turn moves one stop along his road, from Tainan to Kentucky to the dish pit to the booth to CUDA.
- **`/jensen`:** prints the whole road and marks where you are on it.

Thank you, Jensen. Hope you are well.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install the-booth --marketplace marknorland/the-booth
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```
claude plugin install the-booth --marketplace marknorland/the-booth
```

In the desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `marknorland/the-booth`, then **Add plugin**.
